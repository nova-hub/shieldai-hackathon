ShieldAI — AI-Powered Phishing Detection Platform

🔐 A cybersecurity tool for identifying potentially suspicious URLs and emails.

🌐 Live Demo: https://shieldai-hackathon.netlify.app/

Overview

ShieldAI is a web-based cybersecurity project designed to help users recognize potential phishing threats. It provides a simple interface for analyzing URLs and suspicious email content, understanding risk levels, and reviewing security recommendations.

Features

- URL Phishing Scanner: Analyze URLs for potentially suspicious patterns.
- Email Analyzer: Review email content for common phishing indicators.
- Risk Overview: View security risk information.
- Security Recommendations: Get guidance on safer online behavior.
- Scan History: Review scan results displayed by the application.
- Responsive Dashboard: Access security tools through a clean web interface.

Tech Stack

- React
- Vite
- JavaScript
- HTML and CSS
- Netlify for deployment
- GitHub for version control

Getting Started

Prerequisites

Install Node.js and npm.

Installation

git clone https://github.com/nova-hub/shieldai-hackathon.git
cd shieldai-hackathon
npm install
npm run dev

Open the local URL provided by Vite in your browser.

Production Build

npm run build
npm run preview

How to Use

1. Open the live demo.
2. Enter a URL into the URL scanner or paste suspicious email content into the email analyzer.
3. Review the displayed risk assessment.
4. Read the security recommendations.
5. Review scan history if available.

Project Goal

The goal of ShieldAI is to make phishing awareness more accessible by helping users identify common warning signs before interacting with suspicious links or messages.

Important Note

ShieldAI is an educational cybersecurity project. Its results should not be treated as a guarantee that a URL or email is safe. Detection depends on the checks implemented in the application.
